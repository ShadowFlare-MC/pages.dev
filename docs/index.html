よくある質問 (FAQ)

Eaglercraft 1.14.4 と DeltaClient についてのよくある質問をまとめました。
ここで答えが見つからない場合は、Discord コミュニティにお気軽にお問い合わせください。

🔰 基本的な質問

DeltaClient とは何ですか？

▼

DeltaClient は、Eaglercraft 1.14.4 + OptiFine のブラウザベースのランチャーです。インストール不要で、ブラウザからすぐに Minecraft をプレイできます。パフォーマンス最適化により、低スペック環境でも快適にプレイできるのが特徴です。

Eaglercraft とは何ですか？

▼

Eaglercraft は、Minecraft Java Edition を WebGL にコンパイルしたバージョンです。ブラウザで Minecraft をプレイできるため、インストールやダウンロードが不要です。マルチプレイサーバーにも対応しています。

本物の Minecraft は必要ですか？

▼

いいえ、不要です。DeltaClient はスタンドアロンで動作し、Minecraft Java Edition を購入する必要はありません。ブラウザからすぐにプレイを開始できます。

どのブラウザに対応していますか？

▼

WebGL 対応の最新ブラウザであれば動作します。推奨環境は Chrome, Firefox, Safari, Edge などです。古いバージョンのブラウザでは動作しないことがあります。

Mac でも使えますか？

▼

はい、Mac でもブラウザから使用できます。ただし、WebGL に対応した最新のブラウザが必要です。Safari は特定のバージョンで制限がある場合があります。

⚡ パフォーマンス関連

どのくらいの FPS が出ますか？

▼

OptiFine の最適化により、ほとんどの環境で 60+ FPS が期待できます。ただし、PC のスペックやネットワーク速度により差があります。古い PC でも 30-40 FPS 程度でプレイ可能です。

低スペック PC でも動きますか？

▼

はい。DeltaClient は低スペック環境での動作を最優先に設計されています。レンダー距離やグラフィック設定を調整することで、古い PC でも快適にプレイできます。

シェーダーは対応していますか？

▼

DeltaClient ではシェーダーを無効化し、パフォーマンスを優先しています。これにより、ブラウザ版でも安定した高フレームレートを実現しています。

ブラウザのメモリ使用量が多いです

▼

これはゲームの性質上、ある程度は避けられません。ただし、ブラウザのリソース制限を確認したり、不要なタブを閉じたりすることで、メモリ使用量を削減できます。

🌍 マルチプレイ関連

サーバーに参加するにはどうすればいいですか？

▼

ゲーム内のマルチプレイメニューからサーバーアドレスを入力するか、サーバーリストから選択してください。招待コードがある場合は、そのコードを入力すれば簡単に参加できます。

友人を招待するにはどうしたらいいですか？

▼

現在のワールドの「招待を共有」ボタンから招待コードを生成できます。このコードを友人に共有すれば、友人もワールドに参加できます。

ラグが発生しています

▼

以下の対策を試してください：1) インターネット接続を確認、2) ブラウザのキャッシュをクリア、3) グラフィック設定を下げる、4) 不要なバックグラウンドアプリを終了。それでも改善しない場合は、Discord で報告してください。

プレイヤー数に制限はありますか？

▼

サーバーの設定により異なります。通常、公開サーバーでは 10-50 人が同時にプレイできます。プライベートサーバーではより多くのプレイヤーをホストできる場合があります。

サーバーは 24/7 稼働していますか？

▼

メインサーバーは 24/7 稼働しています。ただし、定期的なメンテナンスのため、一時的にダウンすることがあります。メンテナンススケジュールは Discord で事前告知されます。

💾 セーブデータ関連

セーブデータはどこに保存されますか？

▼

セーブデータはブラウザのローカルストレージに保存されます。ブラウザのキャッシュをクリアするとセーブデータが失われる可能性があります。重要なワールドはバックアップを推奨します。

別の PC でセーブデータを復元できますか？

▼

ブラウザのデータを別の PC に転送することで、理論上は可能ですが、推奨されません。マルチプレイサーバーのデータはサーバー側に保存されるため、別の PC からアクセスできます。

ワールドをダウンロードできますか？

▼

現在のバージョンではワールドのダウンロード機能はありません。ただし、今後のアップデートで実装される予定です。

セーブデータが失われた場合はどうすればいいですか？

▼

ブラウザのローカルストレージに復元できない場合、復旧は困難です。重要なワールドは定期的にバックアップすることをお勧めします。ただし、サーバーのデータは別に保存されているため、サーバーに参加すれば復旧できます。

🔧 トラブルシューティング

ゲームが起動しません

▼

以下を確認してください：1) ブラウザが最新版か、2) WebGL が有効か、3) Javascript が有効か、4) ブラウザのキャッシュをクリア。それでも起動しない場合は、別のブラウザを試してください。

「WebGL not supported」というエラーが出ます

▼

お使いのブラウザが WebGL に対応していません。以下を試してください：1) ブラウザを最新版に更新、2) 別のブラウザを試す（Chrome, Firefox を推奨）、3) GPU ドライバを更新。

キーボード入力が反応しません

▼

ゲーム画面がアクティブになっていることを確認してください。クリックしてフォーカスを取得してから入力してください。問題が続く場合は、別のキーボードで試すか、ブラウザを再起動してください。

画面がちらつきます

▼

これは GPU ドライバの問題の可能性があります。以下を試してください：1) GPU ドライバを更新、2) ブラウザの硬件アクセラレーションを無効化、3) グラフィック設定を下げる。

Discord にログインできません

▼

ブラウザのポップアップブロックが有効になっていないか確認してください。また、3rd パーティクッキーが有効になっているか確認してください。それでも解決しない場合は、ブラウザを再起動してみてください。

👥 コミュニティ関連

Discord コミュニティに参加するにはどうしたらいいですか？

▼

ホームページの Discord リンクをクリックするか、「サーバー」ページから直接参加できます。コミュニティではイベント情報や助言を受けることができます。

チートやハックの使用は許可されていますか？

▼

いいえ。マルチプレイサーバーではチート、ハック、不正行為は禁止されています。違反したアカウントは永続的にバンされる可能性があります。

建築系のイベントはありますか？

▼

はい。定期的に建築コンテスト、生存挑戦、PvP イベントなど、様々なイベントを開催しています。詳細は Discord で告知されます。

サーバーに問題を報告するにはどうしたらいいですか？

▼

Discord の「#バグ報告」チャンネルで報告してください。詳細な説明と、問題を再現するための手順を含めていただくと、より迅速に対応できます。

🔒 セキュリティとプライバシー

データは安全ですか？

▼

はい。ゲーム内データはローカルストレージに暗号化されて保存されます。ただし、ローカルストレージはブラウザのセキュリティに依存するため、100% 安全とは言い切れません。重要なデータのバックアップをお勧めします。

個人情報を集められていますか？

▼

DeltaClient はプレイヤー名とゲーム統計情報のみを収集します。個人情報（メール、住所など）は収集していません。詳細はプライバシーポリシーをご覧ください。

Minecraft アカウントに接続する必要がありますか？

▼

いいえ。DeltaClient はスタンドアロンで動作し、Minecraft アカウント接続は不要です。プレイヤー名のみで遊べます。
